# トップページの案（デザインのキャンバスで本人が決めたもの）

Claude（チャット）がデザインのキャンバスで作り、本人が「これでいこう」と決めた案を、文章とアイコンの形で書き写したものです。色は issue 015 の決まりに合わせて読みかえてください（下の「色の読みかえ」）。

## 1. 全体の並び（上から）

1. **見出しの行**
   - 左：小さい補足「今日は 11月8日（季節の終わりまで、あと 23 日）」、その下に見出し「2026年 秋（9月〜11月）」
   - 右：ボタン 2 つを横に並べる。「予実比較を見る」（白地に枠のボタン）、「取引を登録」（主ボタン。文字の左に「＋」のアイコン）
   - 幅がせまいときは、ボタンは見出しの下に折り返す
2. **季節のメーター**（白いカード、全幅）
   - カードの中を左右に分ける。幅がせまいときは上下
   - 左：小さい見出し「この季節に使った合計」、その下に大きな数字「84,326円」と小さく「/ 予算 130,000円」、その下に「残り 45,674円」
   - 右：棒の上に、左「予算のうち 65% を使った」、右「縦の線は『今日』（季節の 72%）」。その下に棒（太さ 16px くらい）と「今日」の縦線
3. **2 列の部分**（992px 以上で 2 列。左の列は幅 300〜400px くらい、右の列は残り全部。せまいときは縦に並べる）
   - **左の列**：上に「今週 何に使ったか」の円グラフのカード、その下に「きょうのひとこと」のカード
   - **右の列**：「今週の進み具合」（科目ごとのメーター）のカード

## 2. 円グラフのカード（左の列の上）

- 見出し「今週 何に使ったか」、その下に小さく「11月8日（日）〜 11月14日（土）」
- 真ん中に円（ドーナツ。直径 220px くらい）。円の中に小さく「今週の合計」、大きく金額
- 円の下に、科目の一覧（色の四角・科目名・金額・割合を 1 行ずつ）
- いちばん下に小さく「金額は 100円単位で切り上げ。今週まだ使っていない科目は出ません。」

## 3. きょうのひとことのカード（左の列の下）

- 白地、枠の線、**左だけ太いターコイズの線（4px）**、角は 16px
- 見出し「きょうのひとこと」（小さめ、濃いターコイズの文字）
- 中は 2 行。それぞれ「左にアイコンの四角（36px、角 10px、薄いターコイズの地、濃いターコイズのアイコン）＋右に文」
  1. 暦のひとこと：アイコンは「太陽」（下の 4. の「暦」）。文の上に小さく「七十二候（立冬の初候）」、太字で「山茶始開（つばきはじめてひらく）」、その下に本文。次の節気までの日数もこの中に
  2. グラフへのひとこと：アイコンは「円グラフ」（下の 4. の「グラフ」）。文は 1 行

## 5. 今週の進み具合のカード（右の列）

- 見出し「今週の進み具合」、右に小さく「縦の線は『今日』（週の 〇 日目）」
- その下に小さく、週の予算の決め方の説明（「科目の週の予算 ＝ 今日が入っている季節の予算 ÷ 13（100円単位で切り上げ）…」）
- 合計の行（太め、棒 14px）→ 区切り線 → 科目ごとの行
- 科目ごとの行：1 行目に「科目名（太字）＋ 状態の短い文（例：『赤：1,100円オーバー』『💮 予算内』『青：1/3以下』『予算なし』）」と、右に「実績 / 週の予算」。2 行目に棒（10px）と「今日」の縦線。💮 の行は背景 #FFF2E5、角 10px
- いちばん下に小さく、色の説明

## 6. 色の読みかえ（issue 015 の決まりを優先）

- 案では #0E9594 を棒やロゴの地にも使っていたが、今の決まりでは #0E9594 は枠の線だけ。**ロゴの四角の地は主ボタンの地 #0B7F7E**（白いアイコンとの比 4.83）、棒と円は `--hb-chart-…` の色を使う
- 薄いターコイズ #E1F3F2 は、今のメニューと、ひとことのアイコンの四角（小さな印）にだけ使う
- 文字の大きさ・太さは issue 015 の 4 段（1.75／1.25／1／0.8125rem）と、見出し 700・本文とボタン 400 に合わせる。季節のメーターの大きな数字だけは、見出しと同じ 1.75rem でよい

# ほかの画面の案（同じキャンバスのボード）

キャンバスには 6 つのボードがある。どこまで実装に入ったかは次のとおり。

| ボード | 中身 | 実装 |
|---|---|---|
| 余白と文字の決まり | 文字 4 段、余白、角の丸み、色 | issue 015 で済み |
| 色とフォントの見比べ | 候補を並べただけ | 決めるための資料（ターコイズと Zen Kaku Gothic New に決定） |
| 取引の登録画面 PC 向け | 2 列のフォーム | issue 015 の 3 回目で済み |
| トップページ | この文書の 1〜6 | 一部だけ（並び・アイコン・見出しがまだ） |
| メニューと共通の枠 | ヘッダーと取引一覧 | まだ（下の 7） |
| ログイン画面 | 2 列のログイン画面 | まだ（下の 8） |

## 7. メニューと共通の枠（全画面のヘッダー）と取引一覧

- **ヘッダー**：白い帯、下に区切り線。中身は横に 3 つ
  1. 左：ロゴ（34px の角丸の四角に白いアイコン。地は主ボタンの地の色）＋太字「家計・予実管理」。押すとトップへ
  2. 真ん中：メニュー 7 項目（4 節のアイコン＋文字、高さ 44px、角 10px）。今いる項目は薄いターコイズの地・濃いターコイズの文字・太字。ほかは灰色の文字
  3. 右：「〇〇 さん」と「ログアウト」（白地に枠のボタン）
  - 幅がせまいときは、メニューが折り返す
- **取引一覧**
  - 見出しの行：左に見出し「取引一覧」、その下に小さく「日付の新しい順に、〇 件を表示しています。」。右に「取引を登録」（主ボタン、「＋」のアイコン）
  - 表は白いカード（角 14〜16px）の中。列は「日付・科目・取引先・支払方法・金額・操作」。見出しの行は小さめの灰色の文字。日付と支払方法は灰色、金額は太字・右寄せ・桁をそろえる。操作は「詳細」のリンク
  - 幅がせまいときは、表を横にスクロールできる（表をカードの中で横に動かす）

## 8. ログイン画面

- ヘッダーは、ロゴと「家計・予実管理」だけ（メニューとログアウトはない）
- 本体は 2 列（幅がせまいときは縦に並べる。ログインの欄が下になってもよいが、スマホでは先に出したいなら順番を Q にする）
  - **左（紹介）**
    - 小さなチップ「季節ごとの家計簿」（薄いターコイズの地、濃いターコイズの文字）
    - 大きな見出し「予算と実績を、<改行>3 か月ごとにふり返る。」
    - 説明「取引を記録すると、季節（春・夏・秋・冬）ごとに、科目別の予算と実績が並びます。予算内に収まった科目には 💮 が付きます。」
    - チェックの印（小さな四角に ✓）付きの 2 行：「自分のデータは、自分だけが見られます」「科目・取引先・支払方法は、自由に追加できます」
  - **右（ログインのカード）**：白いカード（角 18px、うすい影）、見出し「ログイン」、ユーザー名・パスワードの欄（ラベルは上、高さ 46px）、幅いっぱいの主ボタン「ログイン」、下に区切り線と「はじめての方は アカウント登録」
- チェックの印のアイコン：`<path d="M5 12l5 5 9-10"></path>`（stroke-width 2.6）
- 説明の 💮 の文は、予実比較の決まり（1/3 を超えて予算以下）と食い違わない言い方か、作るときに確かめる
- アカウント登録の画面も、同じ形にそろえるかを Q にする
