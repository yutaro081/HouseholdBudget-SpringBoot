# 024：画面の仕上げ（Gemini に画面を見てもらった意見から）（候補）

## 概要

Gemini に画面を見てもらった意見のうち、**入れることにしたもの**と、**入れないことにしたもの〔理由つき〕**を記録する。入れるものは、見た目と言葉の仕上げで、**計算や保存の決まりは変えない**。

## 入れるもの

### ログイン画面

- 左の紹介のチェック項目を、**「着地見込み」と「自動予算」の 2 つに差しかえ**、「**自分のデータは、自分だけが見られます**」を **3 つ目に残す**〔今のチェックは「自分のデータは、自分だけが見られます」「科目・取引先・支払方法は、自由に追加できます」〕。
- 理由：このアプリの目玉の機能が、ログイン画面で伝わる。

### 予算設定

- **自動予算の文と、1〜3 の切りかえボタンを、白いカードにまとめる**〔左に 4px のターコイズの線。**複写のお知らせ〔`alert-info`〕と同じ形**。設計書 2.3「色の決まり」〕。
- **案のもとにした数字の目印**〔issue 020〕を、ターコイズの**下線**〔リンクに見える〕から、**薄いターコイズの背景＋太字**に変える。**注記の文も合わせる**〔今は「ターコイズの下線：案のもとにした数字」〕。薄いターコイズは「小さな印」に使う決まりなので、決めるときに確かめる〔設計書 2.3〕。
- **予算額の入力欄の数字と、合計の行の数字の、一の位を縦にそろえる**〔右寄せの右端が、入力欄の内側の余白の分、ずれている〕。

### 予実比較

- **要約カードの並びを「予算 → 実績 → 見込み」にし**〔今は「見込み → 予算 → 実績」〕、**見込みの横に「予算より 約 ○円 少ない（多い）見込み」を添える**。**💮 は付けない**〔💮 は、実績の印のため〕。
- **残りと見込みの間の区切り線を、少し濃くする**〔issue 020 で入れた、薄い縦の線〕。

### すべての表

- **すべての表を、白いカード**〔角丸・薄い枠。取引一覧と同じ形〕に入れる〔科目・取引先・支払方法の一覧、予算設定、予実比較〕。

### 取引一覧

- セルの「**円**」をやめ、見出しを「**金額（円）**」にする〔予算設定・予実比較と同じ決まり〕。
- **行にマウスを乗せたら、薄く色が付く**。

### 科目・取引先・支払方法

- 入力欄の**右に**「**追加**」ボタンを**並べる**。

### 言葉

- **ボタンの言葉をそろえる**：「保存」「追加」と、「登録する」の、**どちらかに**〔どちらにするかは、決める〕。[issue 021](021-お知らせの色をそろえる.md) の「言葉もそろえる」と、**まとめて考える**とよい。

## 入れないと決めたもの〔理由つき〕

- **予算設定の列の並びは、変えない**。〔本人の判断。「科目 → 根拠 → 予算額 → 前の季節の実績 → 前の季節の予算」のまま〕
- **予実比較の見込みの列の「/ 予算」は、残す**。〔本人の判断。見込みと予算を、見比べやすくするため〕
- **表の見出しのターコイズは、やめない**。〔「**その画面の主役の列の見出しを、ターコイズにする**」という **1 つの決まり**で、そろっているため：予算設定は「予算額」、予実比較の今の季節は「残り」「見込みとの差」、過去・未来の季節は「差額」。**この決まりを、設計書 2.3 に書く**〕
- **取引の登録画面の日付の欄は、今の幅のまま**。〔[issue 017](017-デザインの案どおりにする.md) の決定〕
- **円グラフの色は、この issue では扱わない**。〔[issue 021](021-お知らせの色をそろえる.md) で考える〕

- ボタンの言葉〔上の「言葉」〕。
