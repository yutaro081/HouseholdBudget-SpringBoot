# 015：画面の見た目をそろえたい（色・フォント・文字の大きさ・余白。取引の登録・編集画面は PC で 2 列）

## 概要

画面の見た目を、**ターコイズを基本の色**にして、全画面でそろえたい、という要望。あわせて、**フォント**（Zen Kaku Gothic New）を入れ、**取引の登録・編集画面を PC で 2 列**にする。**3 回に分けて実装した**〔1 回目：色、2 回目：フォント、3 回目：取引の登録・編集画面の 2 列〕。**`v1.3.0` で完了**〔下の「対応状況」。2026年11月8日〕。この issue は、はじめは記録だけ〔文書だけ〕で、コードも要件定義書も設計書も変えていなかったが、実装のとき、要件定義書・設計書を先に直した。

アプリの動き〔何ができるか〕は変えない。**見た目と、画面の並べ方だけ**を変える。ただし、💮 の行の背景色の変更は、**要件定義書の文**〔「薄い緑」〕に関わるので、要件定義書から直す（下の「文書で直す所」）。

**別の issue にするもの**（この issue には入れない）：トップページ〔[issue 010](010-グラフを作成したい.md) の書き直し〕、「きょうのひとこと」。

## 要望の内容

- 要望：色・フォント・文字の大きさ・余白・角の丸みの**決まり**を作り、全画面に当てて、見た目をそろえたい。取引の登録・編集画面は、PC で見やすい 2 列にしたい。
- 理由：今は Bootstrap の標準の見た目〔青い主ボタン、標準の文字〕のままで、画面ごとの統一感が弱い。デザインの案を作り、**基本の色、フォント、2 列の画面**を、本人が決めた。
