# 031：ページ移動のなめらかな切りかわり（View Transitions）（対応中）

> **状態（2026年11月17日）**：◐ **段階 ①〔文書〕を行った**〔確認待ち〕。手順書は [issue-031-view-transitions.md](../plans/issue-031-view-transitions.md)。

## 概要

画面を移るとき、今は一瞬で入れかわる。CSS の `@view-transition { navigation: auto; }` で、移動の切りかわりをなめらかにする。**小さくやり、実機で見てよくならなければ外す**〔外すことは、手順書の決まりに書いた〕。JavaScript は使わない。

## 要望の内容〔2026年11月17日・本人〕

1. 画面移動の切りかえを、CSS だけでなめらかにする〔JavaScript なし・CDN なしの決まりは守る〕。
2. ヘッダーまで一緒にふわっと切りかわると、かえって落ち着かない。ヘッダーは動かさない。
3. 「動きを減らす」設定のときは、切りかえを始めない。
4. 効果は小さいと考えている。実機で見てよくならなければ外す。

## 調べた結果〔2026年11月17日〕

- 対応：Chrome・Edge 126 から、Safari は 18.2 から〔Chrome の公式ドキュメントの表示〕。Firefox は対応していない。MDN は「Limited availability」〔Baseline ではない〕と書いている。対応していないブラウザでは、規則が無視されるだけで、ふつうに移動する。
- 対象は、同じオリジンの移動。戻る・進む、と、ページの中の操作で始まった移動。アドレスバー・ブックマーク・リロードは対象外。4 秒を超えると、切りかえは取りやめになる。
- `view-transition-name` が同じ名前の要素が 2 つあると、切りかえそのものが取りやめになる〔MDN〕。
- 出典：[Chrome：cross-document view transitions](https://developer.chrome.com/docs/web-platform/view-transitions/cross-document)、[MDN：@view-transition](https://developer.mozilla.org/en-US/docs/Web/CSS/@view-transition)、[MDN：view-transition-name](https://developer.mozilla.org/en-US/docs/Web/CSS/view-transition-name)。
- 確かめられていないことは、手順書の 3 章に書いた。

決まったことの一覧と、実機で確かめることは、手順書にある。
