# 021：お知らせ（alert）の色を、アプリの色にそろえる（候補）

> **状態（2026年11月11日）**：☐ **候補**〔調べた結果の一覧だけ。**直すのは別の機会**。要件定義書・設計書・コードは、まだ変えていない〕。

## 概要

画面の「お知らせ」の枠〔Bootstrap の `alert`〕のうち、**黄（`alert-warning`）・緑（`alert-success`）・赤（`alert-danger`）は、Bootstrap の標準の色のまま**。アプリの色〔ターコイズ、設計書 2.3「色の決まり」〕とそろっていない。特に **`alert-danger` の赤は、エラーの赤 `#B02A37`（入力エラーの文字・削除ボタン）と違う**〔お知らせの文字 `#58151C`、地 `#F8D7DA`、枠 `#F1AEB5`〕。

issue 019 のブラウザの確認で、「Bootstrap の青が残っていないか」を調べたときに分かった〔青は 1 か所〔複写のお知らせ `alert-info`〕だけで、そこは issue 019 の中で直した〕。

## 決めること（この issue を進めるとき）

- 4 種類〔成功・失敗・案内・複写のお知らせ〕を、**どの見た目にそろえるか**。案：複写のお知らせと同じ「白い地、左 4px の線、本文の色」で、線の色だけ変える〔成功＝ターコイズ、失敗＝エラーの赤 `#B02A37`、案内＝補足の灰色〕。色だけに頼らず、文でも分かる〔今も文で書いてある〕。
- 失敗のお知らせの赤を、エラーの赤 `#B02A37`〔背景 `#F6F8F8` の上で 6.09 対 1〕に**そろえるか**。そろえる場合は、設計書 2.3 の色の表と、`ColorSchemeStyleSheetTest` に足す。
- 緑・黄の標準の色を、アプリの色の決まり〔設計書 2.3〕に**入れるか、やめるか**。
- 文字と地の明るさの比は、4.5 対 1 以上〔issue 015 の目安〕。

## 言葉もそろえる〔2026年11月11日に足した〕

**同じ意味の言葉が、画面ごとに違う。どちらかにそろえる**〔色の次に、言葉〕。

| 意味 | トップの今週のメーター〔`messages.properties` の `top.status.*`、注記〕 | 予実比較〔チップ、注記〕 |
|---|---|---|
| 予算を超えた | 「**赤：○円オーバー**」〔金額つき〕。注記「赤：週の予算を超過」 | チップ「**予算超え**」。注記「残りの赤：予算超え」 |
| 予算の 1/3 以下 | 「**青：1/3以下**」。注記「青：週の予算の1/3以下」 | チップ「**使い残し**」。注記「青：使い残し（予算の1/3以下）」 |
| 予算内 | 「予算内」〔💮〕。注記「💮：週の予算内（1/3を超え、予算以下）」 | 注記「💮：予算内（予算の1/3を超え、予算以下）」 |
| 予算がない | 「予算なし」 | 「未設定」 |
| 見込みが予算を超える〔予実比較だけ〕 | — | チップ「超える見込み」 |

- 色の意味〔赤・青・💮〕は同じなのに、**言葉が違う**〔「オーバー」と「予算超え」、「1/3以下」と「使い残し」、「予算なし」と「未設定」〕。
- **決めること**：どちらにそろえるか。案：
  - **A（予実比較にそろえる）**：トップも「予算超え」「使い残し」にする〔金額は、「予算超え 600円」のように後ろに添えるか、別にするか、決める〕。理由：予実比較は、チップの言葉が、短くて意味が分かる〔「1/3以下」は、数字を知らないと意味が分かりにくい〕。
  - **B（トップにそろえる）**：予実比較のチップも「オーバー」「1/3以下」にする。理由：金額が分かる。
  - 「予算なし」と「未設定」は、画面の季節の話〔予算の欄が空〕か、週の話か、で使い分けるか、どちらかにするか。
- 直す所：`messages.properties`〔`top.status.*`〕、`top/index.html` と `comparison/index.html` の注記・チップ、設計書 2.3、要件定義書 4.4・4.5〔言葉が書いてある所。前と後の文を、本人に見せてから〕、それを確かめている既存のテスト。
