# 033：Spring Boot を 4.2 に上げる（対応済み）

> **状態（2026年11月22日）**：● **完了**。Spring Boot 4.2.0 に上げた。ブラウザでの確かめ〔手順書 4 章の 1〜8〕は、すべて期待どおり。`.\mvnw clean test` は 2,921 件成功。手順書は [issue-033-spring-boot-4.2.md](../plans/issue-033-spring-boot-4.2.md)。

## 概要

Spring Boot を 4.1.3 から 4.2.0 に上げる（2 番目の数字の版上げ）。VS Code に「Newer minor version of Spring Boot available: 4.2.0」が出ていて、面接がしばらくない今のうちに上げる。アプリの機能は変えない。

## 要望の内容

- 4.2.0 に上げる。4.2.1 は待たない〔4.2.1 が出たら、あとで 3 番目の数字の版上げとして上げる〕。
- 調べている途中で、前からある問題が見つかった：`application.properties` の `server.error.include-*` の 4 行〔エラーの詳細を画面に出さない設定。設計書 7.7、S2〕は、Spring Boot 4.0 で名前が `spring.web.error.include-*` に変わっていて、**読まれていなかった**。標準の値も「出さない」なので、画面は安全なままだったが、S2 の「標準任せにしない」が守られていなかった。版上げの前に、4.1.3 のままで直す〔段階 1〕。

調べた結果と決まったことは、手順書の 1 章・2 章にある。

## 対応状況

対応済み〔2026年11月22日〕。段階 0〔文書〕、段階 1〔`server.error` を `spring.web.error` に直した。4.1.3 のまま〕、段階 2〔4.2.0 への版上げ〕、段階 3〔本人のブラウザでの確認〕、段階 4〔README・CLAUDE.md・`docs/testing.md`〕。後回しの候補が 1 つある〔手順書 7 章：Mockito の注意〕。
