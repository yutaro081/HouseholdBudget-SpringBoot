# 014：README に、30 秒ほどのデモ動画（または GIF）を付けたい

## 概要

README に、30 秒ほどのデモ動画（または GIF）を付けたい、という要望。採用担当の人は、アプリを手元で起動しないので、**動いている様子**を見せるため。**実装〔撮影と README への追加〕は予定している**が、**今は記録だけ**で、README も画像もコードも変えない。**アプリの機能の追加ではない**ので、要件定義書・設計書は直さない見込み。

## 要望の内容

- 要望：README に、30 秒ほどのデモ動画（または GIF）を付けたい。
- 理由：採用担当の人は、アプリを手元で起動しない。今の README の画像〔静止画 7 枚〕は、画面の形は伝わるが、**操作すると画面が変わる**〔予実比較の色が変わる、など〕ことは伝わりにくい。
- **このデモ動画があれば、就職活動のためのデプロイ〔Phase 10〕は要らない**、と判断した〔2026年11月4日。本人の判断〕。Phase 10 は、**クラウドで動かす経験を学びたいとき**の候補として残す〔実行計画書の Phase 10 の説明に書いた〕。

## 内容の案（30 秒ほど）

1. `demo` でログインする。
2. 予実比較〔2026 年秋〕を開く。交通費が**青**〔予算 25,000 円、実績 5,000 円〕。
3. 取引の登録で、**交通費 5,000 円**を登録する〔日付は、2026 年秋の中。今日の日付が秋の中なら、初期値のまま〕。
4. 予実比較に戻ると、交通費の実績が 10,000 円になり、**青から 💮 と薄い緑の背景に変わる**〔10,000×3 ＝ 30,000 ＞ 25,000、かつ 10,000 ≦ 25,000。Phase 9 の手順書 3.3 の判定のとおり〕。合計行は、💮 のまま。
5. **撮ったあと、その取引を消す**〔`demo` のデータを、元の状態に戻す。取引一覧は 8 件のまま〕。

〔案の確認：予算・実績の数字は、Phase 9 の手順書 3.3 の「期待する予実比較」の表のとおり。**撮る前に、画面で実際にその変わり方になることを確かめる**〕。

## 決めること

- **MP4 か GIF か**：
  - MP4：Windows の「Snipping Tool」〔切り取りツール〕で録画できる。きれいで、軽い。**GitHub の README に、リポジトリの中のファイルを、そのまま動画として埋め込めるか**を、先に確かめる〔画像のように `![](…)` で表示されるとは限らない。リンクになるだけの場合は、押すとダウンロード・別画面になる。GitHub のページに動画をアップロードして使う方法もあるが、README に別の URL が入る〕。
  - GIF：README に画像のように埋め込め、**押さなくても動く**。ただし、ファイルが大きくなりやすく、色が粗くなる。MP4 からの変換〔別の道具が要る〕、または GIF を直接録画できる道具を使う。道具は、**ライセンスと、写り込みのない録り方**を確かめてから選ぶ。
  - 両方〔MP4 を元にして、README には GIF〕にする案もある。
- **ファイルの置き場所と大きさ**：`docs/images/` に置く案〔画像と同じ場所〕、または `docs/media/` など。画像の決まりは「1 枚 300KB 前後まで」〔Q9-5〕だが、**動画・GIF は、それより大きくなる**。上限をいくつにするか〔例：数 MB まで〕。リポジトリが重くならないこと。**`.gitattributes` に、バイナリとして扱う指定を足す**〔画像と同じ。`docs/images/*.png binary` の例〕。撮り直すたびに古いファイルが履歴に残るので、撮り直しの回数を減らす。
- **録る範囲**：**ブラウザの中だけ**〔アドレス欄、タブ、ブックマーク、通知、タスクバー、ほかのウィンドウが写らないこと〕。Windows の録画のツールで、範囲をブラウザの中身だけに指定する。画面の幅は、画像と同じ〔開発者ツールのデバイスツールバーで幅を決める、など〕にそろえるか。通知を止めてから録る〔集中モードなど〕。
- **写り込みの確認**：画像のとき〔Phase 9 の 4.4〕と同じ。**1 コマずつ**〔または何秒かおきに〕確かめる：ユーザー名は `demo` だけ。パスワードの入力は、**録らない**〔ログインは、先にログインした状態から始めるか、入力する場面を切る〕。IP アドレス、PC 名、フォルダのパス、接続先、通知、開発者ツール、ほかのアカウント〔`test1`・`test2`〕が写らない。摘要・科目名・取引先名は、デモ用の作り物だけ。本人と Claude Code の両方で確かめる〔Claude Code は、動画を直接は見られないので、**コマを書き出した画像**で確かめる形になる〕。
- **音**：入れない〔録音しない〕。字幕や説明文を、README の動画の近くの文章で補う。
- **README のどこに置くか**：「このアプリについて」の画像〔`06-comparison.png`〕の近く、または「画面の紹介」の先頭。静止画の代わりにするか、足すか。代替テキストを書く〔動画・GIF の内容を文で説明する〕。
- **古くならないようにする**：画面を変えたら、撮り直すか。issue 008 のブラウザを自動で動かすテストで、動画を撮れるか〔Playwright は録画できる〕は、008 の検討に足してよい。
- **データの扱い**：撮ったあとに、取引を消して `demo` を元に戻す〔取引一覧 8 件、2026 年秋の予実比較が 3.3 の表のとおり〕。撮り直すと、そのたびに同じ取引を登録して消すことになる。
- **変える文書**：README〔動画の追加〕、実行計画書〔候補の一覧、Phase 10 の説明〕。手順書〔Phase 9 の続きとして、または新しい Phase に置くかは、行うと決めたときに決める〕。
