## 1. 目的

同じような取引をくり返し入れる手間を減らします。次の 4 つがそろった状態にします。

- 取引の**詳細画面**に「この取引を写して登録」ボタンがある。
- 押すと、登録画面が、写す元の取引と**同じ内容**（科目・取引先・支払方法・金額・摘要）が入った状態で開く。**日付だけは今日**。
- **写しただけでは保存しない**。「登録」を押したときに、ふつうの登録と同じ入力チェックをして保存する。
- 写す元の取引は変わらない。

**JavaScript は足さない**（リンク〔GET〕でサーバーが値の入った画面を作る）。

### 3.1 画面の動き（案）

1. 詳細画面で「この取引を写して登録」を押す → `GET /transactions/new?copyFrom=（その取引の ID）`。
2. Controller は、`copyFrom` があれば `transactionService.get(userId, copyFrom)` で探す。見つからなければ 404。
3. 見つかれば、`new TransactionForm(transaction)` に**日付だけ今日**を入れて、登録画面を表示する。画面のタイトルは「取引の登録」のまま。
4. 「登録する」を押す → `POST /transactions/new`〔今の処理そのまま。入力チェック、保存、「登録しました」〕。**入力エラーで表示し直した画面は、ふつうの登録画面と同じ**〔`copyFrom` は送られないので、複写の 1 行は出ない。入力した値は残る〕。
5. 金額の欄に値が入っているので、**税込のボタンは最初から押せない**〔issue 009 の Q009-18。コードは変えない。Q012-3〕。
