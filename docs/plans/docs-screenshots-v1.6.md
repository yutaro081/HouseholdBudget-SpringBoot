### 5.5 動画の見どころは、4 件を足したあとも成り立つか〔確かめた〕

**成り立つ**。

- **交通費**：4 件を足すと **5,600 円 / 25,000 円**。5,600 × 3 ＝ 16,800 ≦ 25,000 なので**青**。
- 動画で **5,000 円**を足すと **10,600 円**。10,600 × 3 ＝ 31,800 ＞ 25,000、かつ 10,600 ≦ 25,000 なので、**青から 💮 に変わる**。
- **ほかの科目は変わらない**〔食費＝赤、雑費・日用品＝💮、交際費＝青、娯楽＝色なし〕。合計は 92,000 → **97,000 円**〔97,000 × 3 ＝ 291,000 ＞ 130,000、かつ ≦ 130,000〕で、**💮 のまま**。
- 削除すると、5,600 円〔青〕・92,000 円に戻る。
- 判定は `BudgetColorJudgeTest` の 78 件で確かめてある〔境界：ちょうど 1/3、ちょうど予算〕。**この数字では、境界に当たらない**〔1/3 は 8,333 円、5,600 と 10,600 はどちらからも遠い〕。
- **画面で実際にそうなるかは、撮る前に確かめる**〔4 件を足したあと、予実比較を開いて 5.2 の表のとおりか見る〕。
